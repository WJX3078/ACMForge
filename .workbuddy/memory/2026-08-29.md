## 环境坑（本机 Windows + WorkBuddy 沙箱）

- `npm install -g` 走网络会失败（沙箱拦截）→ 改成本地安装到 `C:\Users\asus\.workbuddy\binaries\node\workspace`，用 `./node_modules/.bin/<cmd>` 调用
- `agent-browser` 默认视口只有 1262×568，页面元素常在折叠线以下 → 点击前必须 `agent-browser set viewport <w> <h>`，否则 click 报 "Done" 但状态不变（静默失败，极易误判成应用 bug）
- `agent-browser errors` 是 **daemon 级别累积**的，SPA 内 hash 跳转不会清空 → 每次跳转后要 `errors --clear`，否则旧会话的错误会串到新测试里
- Vite HMR 热替换 hook 文件时 React 会报 "Should have a queue. This is likely a bug in React." —— 这是 dev 环境产物，生产构建无此问题；判断时要 `close --all` 后重测，别误判
