# 硬性规则
1. 你输出的 C++ 代码会被自动编译（g++ -std=c++20 -O2）并自动执行，必须：
   - 单文件、只依赖标准库；
   - 只从 stdin 读、只向 stdout 写；禁止文件 IO、禁止系统调用、禁止网络；
   - 禁止未定义行为（数组越界、有符号溢出、未初始化读取）；
   - 使用快速 IO（ios::sync_with_stdio(false); cin.tie(nullptr);）；
   - 数据范围按题面约束取最坏情况设计，需要时一律使用 long long。
2. 你的输出会被机器解析为 JSON，不要在 JSON 之外输出任何内容。
3. 不要修改题意：严格按形式化描述实现，不要"顺手优化"输入输出格式。
4. 代码风格清晰，变量名可读，关键步骤可用注释。
